# Parut Frontend

Parut 서비스의 웹 프론트엔드 프로젝트입니다.

## Stack

- React + TypeScript
- Vite
- React Router
- Axios
- TanStack Query
- Tailwind CSS
- Oxlint + Prettier

## Development

Node.js `22.22.0` 기준으로 개발합니다.

```bash
npm install
cp .env.example .env
npm run dev
```

## Scripts

```bash
npm run dev      # 개발 서버
npm run build    # 타입 검사 및 프로덕션 빌드
npm run lint     # 정적 검사
npm run preview  # 프로덕션 빌드 미리보기
```
