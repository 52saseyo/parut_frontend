# UI 및 반응형 정책

## 기본 원칙

- 모바일 화면부터 깨지지 않도록 설계합니다.
- Tailwind CSS utility class를 기본으로 사용합니다.
- 반복되는 UI는 공통 컴포넌트로 추출합니다.
- 색상, 간격, 글꼴 크기는 임의의 값을 반복하기보다 공통 기준을 사용합니다.
- 아이콘과 이미지에는 필요한 경우 대체 텍스트를 제공합니다.

## 반응형 기준

- 작은 화면에서 가로 스크롤이 생기지 않아야 합니다.
- 터치 영역은 충분한 크기를 확보합니다.
- 데스크톱 전용 hover 동작에 기능을 의존하지 않습니다.
- 표와 복잡한 콘텐츠는 모바일에서 카드 또는 가로 스크롤 등 대체 표현을 검토합니다.

## 화면 상태

화면은 정상 상태만 구현하지 않고 loading, empty, error, 권한 없음 상태를 함께 설계합니다.
